JavaScript Basics

This page demonstrates basic JavaScript concepts using the attached script.js file.

Console Output Examples

  • Strings and text: console.log("Hello World")
  • Math operations: addition and type checks like 5 + 4 and typeof 5
  • String-to-number conversion: parseInt("100dksfnjnsd") returns 100

Type Conversion

The script shows several ways to convert values between strings and numbers:

  • "" + 100 and 100 + "" convert a number to a string.
  • +"100" and Number("100") convert a string to a number.
  • String(100) converts a number to a string explicitly.

Parsing and NaN

JavaScript can parse numeric values from strings, but order matters:

  • parseInt("100dfjbjds") returns 100.
  • parseInt("dfjbjds100") returns NaN because the string does not start with digits.
  • The type of NaN is still number.

Boolean Conversion

Booleans can also convert to numbers:

  • +false becomes 0.
  • +true becomes 1.
