Variables in JavaScript

This page explains the variable examples in script.js.

Variable Types

The script creates variables for text, numbers, and booleans:

  • let firstName = "Rajiv";
  • let lastName = "Sharma";
  • let age = 24;
  • let isDeveloper = true;

String Interpolation and Concatenation

Use template literals or string concatenation to build text:

  • let bioData = `My name is ${firstName} ${lastName}. I am ${age} years old and I am a developer.`;
  • let bioData2 = "My name is " + firstName + " " + lastName + ". I am " + age + " years old and I am a developer.";

Undefined and Null

JavaScript uses undefined for declared variables without a value, and null for intentionally empty values:

  • let abc = undefined;
  • let xyz;
  • let pqr = null;

Note: typeof null returns "object" due to a historical JavaScript quirk.

Reassigning Variables

Variables declared with let can be reassigned and can hold different types:

  • firstName = "Rahul";
  • firstName = 123;

Constants with const

const values cannot be reassigned after initialization:

  • const country = "India";

Uncommenting country = "USA"; would cause a runtime error.

var and Scope

The script shows how var behaves differently from let:

  • var city = "Mumbai"; can be reassigned and redeclared.
  • var city = true; shows dynamic typing.
  • let blockScopedVariable = "I am block scoped"; is only available inside the block.
  • var functionScopedVariable = "I am function scoped"; is still accessible outside the block.

Hoisting

var declarations are hoisted, so the variable exists before its declaration but has the value undefined. In contrast, let does not allow access before declaration.

Variable Naming Rules

Valid variable names can include letters, digits, underscores, and dollar signs but cannot start with a digit or use reserved keywords.

  • let _myVariable = "Valid variable name";
  • let $myVariable = "Valid variable name";
  • let myVariable1 = "Valid variable name";
