How to See Variable Address in DevTools

Open the browser DevTools (e.g. press F12 or right-click > Inspect).

Go to the Memory tab and take a Heap Snapshot.

After the snapshot finishes, search for the variable name or object in the snapshot view.

The DevTools snapshot shows internal object references such as @12345, which represent the engine's memory handles.

For example, if you define const name = 'Alice';, a heap snapshot may show an entry like name @12345.
