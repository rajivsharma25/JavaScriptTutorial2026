If Else Statement

This is a simple example of an if-else statement in JavaScript.

      const dayNumber = 4;
      if(dayNumber === 0) {
        console.log('It is Sunday Today')
      } else if(dayNumber === 1) {
        console.log('It is Monday Today')
      } else if(dayNumber === 2) {
        console.log('It is Tuesday Today')
      } else if(dayNumber === 3) {
        console.log('It is Wednesday Today')
      } else if(dayNumber === 4) {
        console.log('It is Thursday Today')
      } else if(dayNumber === 5) {
        console.log('It is Friday Today')
      } else if(dayNumber === 6) {
        console.log('It is Saturday Today')
      } else {
        console.log('Please Enter a Valid Day Number')
      }
