Truthy and Falsy Values in JavaScript

In JavaScript, values can be classified as either "truthy" or "falsy". This classification is important when evaluating conditions in control flow statements like if, while, and others.

Falsy Values

The following values are considered falsy in JavaScript:

  • false
  • 0 (zero)
  • -0 (negative zero)
  • 0n (BigInt zero)
  • "" (empty string)
  • null
  • undefined
  • NaN

Truthy Values

Anything that is not falsy is considered truthy:

  • true
  • 1 (non-zero number)
  • "hello" (non-empty string)
  • [] (empty array)
  • {} (empty object)
  • function() {} (function)
